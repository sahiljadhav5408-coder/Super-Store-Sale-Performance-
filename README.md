# Super-Store-Sale-Performance-
An interactive Super Store Sales Performance Dashboard built using Power BI to analyze sales, profit, quantity, customer segments, product categories, regions, payment methods, shipping modes, and sales trends. The project also includes  15-day sale forecasting dashboard to identify future demand patterns and support data driven business decisions.
